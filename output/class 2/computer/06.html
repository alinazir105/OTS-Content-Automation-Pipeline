What is MS Word?
A powerful tool to create and organise documents

In this unit, we will learn essential skills in MS Word that help make your documents look organised. You will learn how to cut, copy, and paste text, apply basic formatting styles, and align text for a better presentation.

💡 Did you know? When you have selected a text or a picture, you can use the right-click option to cut, copy or paste your text instead of using the buttons on the clipboard!

✂️
Cut, Copy, and Paste
Move and duplicate text like a pro!
1
📋 Copy

Use this feature to duplicate text (original stays in place).

  • Select the text you want to copy.
  • Right-click and select Copy or press Ctrl + C
  • Move the cursor to where you want it.
  • Right-click and select Paste or press Ctrl + V
2
✂️ Cut

Use this to move text from one place to another (removes original).

  • Select the text you want to cut.
  • Right-click and select Cut or press Ctrl + X
  • Move the cursor to a new location.
  • Right-click and select Paste or press Ctrl + V

Aligning Text
Position your text left, center, or right

⬅️ Left Align

Aligns text to the left side of the document. This is the default alignment.

Ctrl + L

↔️ Center Align

Centers text in the middle of the document. Great for titles!

Ctrl + E

➡️ Right Align

Aligns text to the right side of the document.

Ctrl + R

💡 Tip: Use alignment to organise text for readability, such as centering a title or aligning paragraphs to the left.

Do You Know? Keyboard Keys
Learn the important keys on your keyboard
🔡

Alphabet Keys

The Alphabet keys are used to type letters (a, b, c ... z).

🔢

Number Keys

The Number keys are used to type numbers (0, 1, 2 ... 9).

⬆️

Arrow Keys

The Arrow keys are used to move the cursor up, down, right, and left.

⇧

Shift Key

The Shift key is used to type uppercase letters and symbols.

⌫

Backspace Key

The Backspace key is used to erase text to the left of the cursor.

⌦

Delete Key

The Delete key is used to erase text to the right of the cursor.

🖊️ Exercise 3: Cut, Copy & Paste Practice
Follow these steps in MS Word to practise cut, copy and paste!

Original Text to Type:

Science Fair Project

"Our class is preparing for the upcoming science fair. For my project, I will be demonstrating how plants absorb water using food colouring."

1
✂️ Cut Text
  • Select the words "science fair" from the heading.
  • Right-click and select Cut or use Ctrl + X
2
📌 Paste Text
  • Place your cursor after the word "project" in the second sentence.
  • Right-click and select Paste or use Ctrl + V
3
📋 Copy Text
  • Select the words "how plants absorb water" in the second sentence.
  • Right-click and select Copy or use Ctrl + C
4
📌 Paste Text Again
  • Place cursor at the beginning of the heading, before the word "project".
  • Right-click and select Paste or use Ctrl + V

✅ Final Result should look like this:

How plants absorb water Project

"Our class is preparing for the upcoming science fair. For my project science fair, I will be demonstrating how plants absorb water using food colouring."

Browsing the Internet Safely

🎯 Learning Objectives

  • Identify a web browser
  • Open a web browser

🌐

What is a Web Browser?

🤖 "I use a web browser to view web pages on the internet!"

A web browser is a special program on your computer. It helps you visit websites and see pictures, videos, and text on the internet.

Some common examples of web browsers are:

🟢
Google Chrome
A fast and popular web browser made by Google.
🔵
Microsoft Edge
A web browser made by Microsoft, built into Windows.
🦊
Mozilla Firefox
A free and open web browser made by Mozilla.
🔘

Navigation Buttons

When you use a web browser, you will see these important buttons at the top:

←
Back
→
Next
↻
Reload

⬅️ Back button — Go to the page you visited before.

➡️ Next button — Go forward to the next page.

🔄 Reload button — Refresh and reload the current page.

📂

Opening a Web Browser

There are two easy ways to open Google Chrome:

1
Double-click on the Google Chrome icon 🟢 on the Desktop.
2
Click once on the Google Chrome icon 🟢 in the Taskbar at the bottom of the screen.

💡 The Desktop is the main screen you see when you turn on the computer. The Taskbar is the bar at the very bottom of the screen.

🔍

Browsing a Given Webpage Using Google Chrome

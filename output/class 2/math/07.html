Ascending Order
Going from smallest to biggest!
Ascending order means we arrange numbers starting from the smallest number and going up to the largest number. It is like climbing up a staircase — each step gets higher!

Think of it as counting up: 1, 2, 3, 4, 5… — each number is bigger than the one before it.
🪜
Going Up!
Smallest number comes first. Numbers get bigger and bigger.
3 → 7 → 12 → 20 → 45
⬆️
Arrow Points Up
The values increase as we move from left to right.
11 → 13 → 15 → 17 → 18

Descending Order
Going from biggest to smallest!
Descending order means we arrange numbers starting from the largest number and going down to the smallest number. It is like going down a staircase — each step gets lower!

Think of a countdown: 10, 9, 8, 7, 6… — each number is smaller than the one before it.
🚀
Going Down!
Largest number comes first. Numbers get smaller and smaller.
45 → 20 → 12 → 7 → 3
⬇️
Arrow Points Down
The values decrease as we move from left to right.
18 → 17 → 15 → 13 → 11

Key Tip: To find ascending order, find the smallest number first, then the next smallest, and so on.
For descending order, find the biggest number first, then the next biggest, and so on. 🎯

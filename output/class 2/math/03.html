What Are Missing Numbers?

When we count numbers in order, each number comes after the previous one. Sometimes a number is hidden (missing) and we need to figure out what it is!

Example: 501, 502, ___, 504, 505
The missing number is 503 because we count up by 1 each time.

Remember: Each number is exactly 1 more than the one before it! 🔢

Introduction

What Are Conditional Sentences?

Conditional sentences show a condition and the result that depends on whether the condition is true or not. They talk about possible or impossible situations, future actions, or general truths.

📌 The Two Parts

  • The Condition — the "if" part of the sentence
  • The Result — what happens if the condition is true

💡 Key Idea

Every conditional sentence has an if-clause (condition) and a main clause (result). The order of these parts can be switched!

🔄 Flexible Order

You can write it either way:

  • "If it rains, we get wet."
  • "We get wet if it rains."

Discovery Zone: The "If" Connection

The word "if" connects two ideas — a cause (condition) and an effect (result). Think of it like a bridge between "what might happen" and "what will follow."


Example: If you heat water → [condition] → it boils → [result]

Grammar Tip

In English, there are four types of conditional sentences (0, 1st, 2nd, 3rd). You're learning the first two — the most commonly used ones!

Type 1

Zero Conditional

Used for facts, general truths, and things that always happen when the condition is met.

Zero Conditional

Formation

Structure If + Present Simple , Present Simple
Example: If you heat water, it boils.

📖 Uses

  • To talk about facts or general truths
  • For things that always happen when the condition is met
  • Scientific facts and universal laws

⚠️ Remember

Both the if-clause and the main clause use Present Simple tense. There is no "will" in zero conditional!

Examples

  • 1
    If the Sun shines, it feels warm.
    ↔ It feels warm if the sun shines.
  • 2
    If you mix blue and yellow, you get green.
    ↔ You get green if you mix blue and yellow.
  • 3
    If you press this button, the light turns on.
    ↔ The light turns on if you press this button.
  • 4
    If you don't water plants, they die.
    ↔ They die if you don't water plants.

Ask yourself: "Is this always true, like a fact or a rule?"

  • Both verbs are in Present Simple tense
  • The result always happens — it's not just a possibility
  • Think: science facts, cooking rules, everyday observations
  • No "will" anywhere in the sentence
Type 2

First Conditional

Used for possible future situations — things that are likely to happen if the condition is met.

First Conditional

Formation

Structure If + Present Simple , will + Base Verb
Example: If it rains, we will stay indoors.

📖 Uses

  • To talk about possible situations in the future
  • For things likely to happen if the condition is met
  • Plans, predictions, warnings

⚠️ Remember

The if-clause uses Present Simple, but the main clause uses will + base verb. Never use "will" in the if-clause!

Examples

  • 1
    If you study hard, you will pass the exam.
  • 2
    If it gets cold, we will light a fire.
  • 3
    If you help me, I will finish faster.
  • 4
    If they play well, they will win the match.

Ask yourself: "Is this something that might happen in the future?"

  • The if-clause has Present Simple
  • The main clause has will + base verb
  • The outcome is possible but not guaranteed
  • Great for making predictions and future plans
Comparison

Zero vs First Conditional

Understanding the key difference helps you choose the right conditional every time.

Type If-Clause Main Clause Use Example
Zero Conditional Present Simple Present Simple Facts & general truths If you heat ice, it melts.
🔍 More detail: Zero conditionals are used for scientific facts, natural laws, and things that always happen. The result is 100% certain whenever the condition happens.
First Conditional Present Simple will + base verb Possible future situations If you study, you will succeed.
🔍 More detail: First conditionals talk about situations that might realistically happen in the future. The condition is possible, and the result is the likely outcome.
Key Difference Zero = always true; First = might be true in the future
🔍 Quick test: Can you replace "if" with "when" and it still makes sense? If yes → Zero Conditional! ("When you heat ice, it melts" ✓). If it sounds odd with "when" → First Conditional!

Let's Analyse Sentences

See how each part of a conditional sentence is labelled and explained.

🔬 Sentence Breakdown: Zero Conditional

"If you mix blue and yellow, you get green."

IF-CLAUSE (Condition)
"If you mix blue and yellow"
Verb: mix (Present Simple)
MAIN CLAUSE (Result)
"you get green"
Verb: get (Present Simple)

✅ Both verbs are Present Simple → Zero Conditional — this is always true!

🔬 Sentence Breakdown: First Conditional

"If you study hard, you will pass the exam."

IF-CLAUSE (Condition)
"If you study hard"
Verb: study (Present Simple)
MAIN CLAUSE (Result)
"you will pass the exam"
Verb: will pass (will + base verb)

✅ If-clause = Present Simple; Main clause = will + base verb → First Conditional — possible future result!

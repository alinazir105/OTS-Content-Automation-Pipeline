Core Concepts

Entering Data & Basic Cell Formatting

In Excel, you enter information (text, numbers, dates) into cells to create tables, lists, and other data structures.

📥 Entering Data

  • 1
    Click on a cell where you want to enter data.
  • 2
    Type your text or numbers into the cell.
  • 3
    Press Enter to confirm and move to the next row.
Cell A1 → Click → Type "Ahmed" → Enter ↵ Data is now stored in cell A1

🎨 Basic Cell Formatting

Formatting makes data easier to read and visually appealing.

🔤
Text & Number Formatting

Change font style, size, or colour to improve readability.

↔️
Alignment

Align text to left, centre, or right within a cell.

🔲
Borders

Add borders around cells to create table-like structures.

🪜 Steps to Format Cells

  • 1
    Select the cell or range of cells you want to format.
  • 2
    Go to the Home tab on the Ribbon.
  • 3
    Use the options to adjust font, colour, alignment, and borders.

Basic Functions

Using the SUM Function

Excel has built-in functions that make calculations simple. The SUM function adds up a range of numbers.

=SUM(A1:A10) Adds all numbers from cell A1 through A10. Always start a formula with =

4 Ways to Use SUM

Method 1

Using SUM from the Ribbon (AutoSum)

  • 1
    Click on the cell where you want the result to appear.
  • 2
    Go to the Home tab on the Ribbon.
  • 3
    In the Editing group, click on AutoSum (∑).
  • 4
    Excel auto-selects the range. Adjust if needed by clicking and dragging.
  • 5
    Press Enter to complete the calculation.
Method 2

Using SUM in the Formula Bar

  • 1
    Select the cell where you want the result to appear.
  • 2
    Click into the Formula Bar (just below the Ribbon).
  • 3
    Type =SUM( then select the range of cells to add.
  • 4
    Close the brackets ) and press Enter.
=SUM(E3:E12) Adds all values from E3 to E12
Method 3

SUM for Non-Adjacent Cells

  • 1
    Click on the cell where you want the result to appear.
  • 2
    Type =SUM( and manually select or type the individual cells.
  • 3
    Separate non-adjacent cells with commas.
  • 4
    Close brackets and press Enter.
=SUM(A1, B3, C5) Adds only cells A1, B3, and C5 (non-adjacent)
Method 4

SUM for Multiple Ranges

  • 1
    Select the cell where you want the result to appear.
  • 2
    Type =SUM( and select the first range (e.g. A1:A5).
  • 3
    Type a comma, then select the second range (e.g. B1:B5). Continue for more.
  • 4
    Close parentheses and press Enter.
=SUM(A1:A5, B1:B5) Adds both ranges A1:A5 and B1:B5 together

💡 Flexibility of SUM

These methods allow flexibility when using the SUM function to add numbers, whether in continuous ranges or separate cells or multiple ranges. You always start with = before any formula in Excel!

Data Types

Simple Formatting by Data Type

Formatting by data type ensures your data displays correctly and is easier to understand.

🔤
Text

For labels, names, or any words. Examples: "Ahmed", "Male", "Food"

🔢
Number

For general numbers; allows options for decimal places. Example: 15, 25, 100.50

💰
Currency

Adds a currency symbol ($ or €) to numbers. Example: $10.00, $25,000.00

📅
Date

Formats entries as dates. Example: 01/01/2024, 6/2/2024

🪜 Steps to Format by Data Type

  • 1
    Select the cell(s) you want to format.
  • 2
    In the Home tab, go to the Number Format dropdown.
  • 3
    Choose the appropriate data type: Text, Number, Currency, or Date.

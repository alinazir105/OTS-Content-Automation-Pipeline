Creating Lists

Bullets & Numbering

Lists make information easy to scan and understand. MS Word 2021 offers 5 types of lists.

🔵

1. Bulleted Lists

Use symbols (•, ▶, ✓) to highlight unordered items. Great for listing features or supplies.

  • Pencil
  • Eraser
  • Notebook
🔢

2. Numbered Lists

Use sequential numbers for ordered steps or instructions where order matters.

  1. Wake up
  2. Get dressed
  3. Eat breakfast
📂

3. Multilevel Lists

Nested lists with different levels — great for outlines, hierarchies, and complex topics.

📑

4. Outline Numbered Lists

Combine numbers and indentation for structured documents like reports and essays.

⚙️

5. Custom Lists

Define your own bullet style or number format using "Define New Bullet" or "Define New Number Format".

🔵 How to Create a Bulleted List

1

Select the text

Highlight the text you want to turn into a list.

2

Go to Home tab

Click the Home tab on the Ribbon at the top.

3

Click Bullets icon

Find the Bullets icon (≔) in the Paragraph section.

4

Choose or customise

Pick a bullet style, or click Define New Bullet to customise.

Location
Home Tab → Paragraph Group → Bullets Icon (≔)

🔢 How to Create a Numbered List

1

Select the text

Highlight the text you want to number.

2

Go to Home tab

Click the Home tab on the Ribbon.

3

Click Numbering icon

Find the Numbering icon (1≡) in the Paragraph section.

4

Choose or customise

Pick a style, or click Define New Number Format for more options.

Location
Home Tab → Paragraph Group → Numbering Icon (1≡)

💡 Did You Know? (Click to reveal!)

📋

Bullet vs Number

Tap to reveal!

Use bullets when order doesn't matter (shopping list). Use numbers when order is important (recipe steps).

⌨️

Keyboard Shortcut

Tap to reveal!

After turning on a list, press Tab to create a sub-level (indent), and Shift+Tab to go back up a level!

✨

Custom Bullet

Tap to reveal!

You can use any emoji or picture as a bullet point! Click the dropdown arrow next to the Bullets button and select "Define New Bullet → Picture".

Tables

Organising Data in Rows & Columns

Tables let you present data neatly so readers can compare information at a glance.

Creating a Table

1

Insert tab

Go to the Insert tab on the Ribbon.

2

Click Table

Click on the Table button.

3

Select size

Drag your mouse over the grid to select rows and columns, then release.

Navigation
Insert Tab → Table → Drag grid to choose size

Formatting a Table

🎨 Table Styles

  • Open the Table Design tab after clicking inside a table
  • Browse dozens of preset styles
  • Match your document's theme

🔗 Merging Cells

  • Select two or more adjacent cells
  • Right-click → choose Merge Cells
  • Useful for creating table headers

↕️ Aligning Text in Cells

  • Right-click the cell → Cell Alignment
  • Choose Top, Middle, or Bottom
  • Also Left, Centre, or Right horizontally

🖱️ Click a row to see more details!

Headers & Footers

Top & Bottom of Every Page

Headers and footers repeat on every page of a document, providing consistent information throughout.

📄 Adding a Header or Footer

1

Go to Insert tab

Find the Insert tab on the Ribbon at the top of MS Word.

2

Click Header or Footer

Choose Header for the top or Footer for the bottom.

3

Choose a style

Select from the built-in styles list — the area opens on the page for editing.

✏️ Formatting Headers & Footers

🔢 Page Numbers

In the Header & Footer tab → click Page Number → choose position (top, bottom, margin).

📅 Date and Time

Click Date & Time in the Header & Footer tab to insert the current date automatically.

📝 Document Title

Simply type the document title directly inside the header or footer area to display it on every page.

🔍 Why Use Headers & Footers?

Headers and footers help make documents look organised and professional. They are especially useful for longer documents — imagine a 20-page report where every page shows the title and page number automatically. You only need to set it up once!

  • Double-click in the header or footer area to edit it.
  • Double-click on the main document body to exit the header/footer edit mode.
  • Use the Different First Page checkbox in the Header & Footer tab to have a unique first-page header.
  • Use Different Odd & Even Pages for book-style layouts.
Quick Path — Header with Page Number
Insert Tab → Header → Choose Style → (edit area opens) → Header & Footer Tab → Page Number → Choose Position
Watermarks & Page Borders

Style & Professionalism

Add visual polish to your document with background watermarks and decorative page borders.

💧 Adding a Watermark

Watermarks are light, faded text or images in the background of every page. Common uses: "CONFIDENTIAL", "DRAFT", school branding.

1

Design tab

Go to the Design tab on the Ribbon.

2

Click Watermark

Find and click the Watermark button.

3

Choose or customise

Choose from the list, or click Custom Watermark to create your own.

4

Add text or image

In a custom watermark, type text like "Off The School" or insert an image.

Path
Design Tab → Watermark → Custom Watermark

🔲 Adding Page Borders

Page borders frame your entire document, giving it a polished, finished look. You can choose styles, colours, and widths.

1

Design tab

Go to the Design tab on the Ribbon.

2

Click Page Borders

Find and click the Page Borders button.

3

Borders and Shading dialog

Choose a style, colour, and width for your border.

4

Click OK

Press OK to apply the border to your entire document.

Path
Design Tab → Page Borders → Borders and Shading → OK
💧

Watermark Fact

Tap to reveal!

Watermarks appear on every page of your document automatically — not just the first page!

🔲

Art Borders

Tap to reveal!

In the Page Borders dialog, there is an "Art" dropdown with fun borders made from small images like trees, hearts, or stars!

🗑️

Remove Watermark

Tap to reveal!

To remove a watermark: Design Tab → Watermark → scroll down and click "Remove Watermark".

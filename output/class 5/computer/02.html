Background

What is Scratch?

A visual programming language designed to make coding fun and accessible for everyone.

Scratch is a visual programming language designed to help beginners create interactive stories, games, and animations. With Scratch, you don't need to write long lines of code. Instead, you use colourful blocks that fit together like puzzle pieces, each containing predefined instructions for controlling characters called sprites.

Scratch makes learning programming simple and fun, making it especially ideal for kids.

Core Concept

The Scratch Interface

The Scratch screen has several important parts. Here's your guide to navigating it!

🎭

Stage

The main area where you see your animations and characters in action. It's like a theatre stage where all the scenes play out.

🐱

Sprite Pane

This shows all the sprites in your project. Each sprite is like a character or an object, and you can add or remove sprites here.

🧩

Block Palette

This area has all the different blocks you can use to control your sprites. Blocks are grouped by colour and function (e.g., Motion, Looks, Sound).

📝

Script Area

This is the workspace where you build scripts by snapping blocks together. Scripts are sequences of instructions that tell the sprites what to do.

Vocabulary

Key Terms in Scratch

Let's learn the important vocabulary you'll use in every Scratch project.

🐱 Sprites

Characters or objects that you can move, change, and animate. Scratch has many sprites to choose from, or you can create your own.

🧩 Blocks

The building blocks of Scratch coding. Each block has a specific function, like moving a sprite or playing a sound. You snap blocks together to create scripts.

📜 Scripts

A set of blocks that work together to perform an action. For example, you can create a script to make a sprite move across the screen.

🌄 Backdrop

The background of the stage. It sets the scene for your animation or game, and you can change it to create different settings.

🎭 Stage

The main display area where sprites perform their actions. Think of it like a theatre stage where all the action happens.

👗 Costumes

Different appearances or outfits for a sprite. Switching costumes quickly creates the illusion of movement or animation.

Core Concept

Scratch Blocks

Here are the basic block categories you'll use often in Scratch.

🔵 Motion Blocks

Control how sprites move around the stage.

move 10 steps
turn 15 degrees
go to x: 0 y: 0

🟣 Looks Blocks

Change the appearance of sprites.

say [Hello!] for 2 secs
change costume
set size to 100%

🩷 Sound Blocks

Add sound effects and music to your project.

play sound Meow
stop all sounds
set volume to 100

🟠 Control Blocks

Manage timing and looping of actions.

wait 1 second
repeat 10 times
forever

🟡 Events Blocks

Start actions in your script — the triggers!

when 🚩 clicked
when sprite clicked
when [space] pressed

🔷 Sensing Blocks

Detect collisions, mouse position, and more.

touching [mouse]?
if touching [wall]
distance to [sprite]

Worked Example

Your First Project

Goal: Make a sprite move and say something!

Script Structure
when green flag clicked ↓ move 10 steps ← Motion Block ↓ say "Hello!" for 2 seconds ← Looks Block ↓ (Optional) play sound ← Sound Block
1

Add a Sprite

In the Sprite Pane, click on the Choose a Sprite button. Select a sprite (like a cat) from the library.

2

Create a Script

In the Block Palette, go to the Events category and drag the "when green flag clicked" block to the Script Area. This block starts your script when you click the green flag.

3

Add Movement

Go to the Motion category. Drag the "move 10 steps" block under the "when green flag clicked" block. Now, when you click the green flag, your sprite will move 10 steps forward.

4

Add Dialogue

Go to the Looks category. Drag the "say Hello! for 2 seconds" block under the "move 10 steps" block. Change "Hello!" to whatever you want your sprite to say.

5

Test Your Script

Click the green flag 🚩 at the top of the Stage. Your sprite should move and say something!

Add the block "if on edge, bounce" from the Motion category! This will make your sprite bounce back when it reaches the edge of the stage instead of disappearing.
Adding Detail

Backgrounds & Sounds

Make your projects more immersive by adding backdrops and sound effects.

🌄 Changing the Backdrop

1

In the Stage area, click on the Choose a Backdrop button.

2

Select a background you like, such as a beach or a city. This will change the backdrop on the stage.

🎵 Adding Sound

1

Go to the Sound category in the Block Palette.

2

Drag the "play sound Meow until done" block to your script. You can choose different sounds or even record your own!

🎨 Drawing Your Own Backdrop

1

Open Scratch

Start a new project at scratch.mit.edu.

2

Go to Backdrop Editor

Click the Stage area → click "Backdrops" tab → click "Paint" to open the drawing tools.

3

Draw Your Backdrop

Use Brush (freehand), Fill (colour areas), Rectangle/Circle (shapes), Line (straight lines).

4

Save & Set Backdrop

Click "OK" to save. Use "switch backdrop to [name]" from the Looks category in your script.

Worked Example

Creating a Simple Animation

Let's create a simple animation where a sprite dances!

Dancing Animation Script
when green flag clicked ↓ switch backdrop to [dance stage] ← Change scene ↓ repeat 10 ← Control Block (loop) next costume ← Looks Block wait 0.2 seconds ← Control Block end ↓ play sound [dance music] until done ← Sound Block
1

Choose a Sprite

Pick a sprite like a dancer from the Scratch library. Dancer sprites come with multiple costumes!

2

Add Costumes

Many sprites have different costumes that show different poses. These create the illusion of movement when switched quickly.

3

Change the Backdrop

Go to the Stage area, click on the Backdrops tab, and choose a backdrop. Drag the "switch backdrop to [your backdrop]" block from Looks to the script area.

4

Create a Loop

Drag the "repeat 10" block from the Control category. Add "next costume" from Looks inside it. Add "wait 0.2 seconds" to control the speed.

5

Play Music

Add a music track from the Sounds category. Now, when you click the green flag, your sprite will dance to the beat!

Replace the "repeat 10" block with a "forever" block from the Control category! The forever block never stops, so your sprite will keep dancing until you click the stop button (the red circle) next to the green flag.

🔬 Lab Activities

🎬 Lab 1: Simple Animation

  1. Open Scratch and start a new project.
  2. Select a sprite from the library or create your own.
  3. Use "move 10 steps" to make the sprite move.
  4. Add a block to make the sprite say "Hello!"
  5. Test by clicking the green flag.

💬 Lab 2: Talking Sprite

  1. Open Scratch and choose any sprite.
  2. Drag "when green flag clicked" to Script Area.
  3. Add "move 10 steps" from Motion.
  4. Add "say Hello!" from Looks.
  5. Click the green flag — watch it move and talk!

🤝 Lab 3: Two Sprites Talk

  1. Choose two sprites (e.g., a person and a pet).
  2. Make the sprites "talk" using the "say" block.
  3. Add different speech for each sprite.
  4. Use "wait" blocks to time their conversations.
  5. Add a backdrop for the setting.

🎮 Lab 4: Obstacle Game

  1. Choose a player character sprite.
  2. Create obstacles that move on screen.
  3. Use "if touching [obstacle]" block to react.
  4. Add sound effects when sprite hits obstacle.
  5. Move sprite with arrow keys or space bar.

❓ Lab 5: Quiz Game

  1. Create a sprite that asks a question.
  2. Add multiple choice options as clickable sprites.
  3. Use "if" blocks to check if answer is correct.
  4. Show "Correct!" or "Try Again" with "say" block.
  5. Track score using a variable.

🚶 Lab 6: Walking Character

  1. Choose a sprite with walking pose costumes.
  2. Use "repeat" to switch between costumes.
  3. Use "wait" to control animation speed.
  4. Move sprite with "glide" or "move" blocks.
  5. Add a backdrop scene for the sprite to walk through.

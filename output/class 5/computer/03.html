What Are Short Keys?

Short keys, also called keyboard shortcuts, make working on a computer faster and more efficient. Instead of using a mouse for every action, you can perform tasks quickly by pressing a combination of keys.


This unit introduces important shortcuts used in MS Word, MS Excel, and general computer tasks.

Importance

Why Do We Learn Short Keys?

Three powerful reasons to use keyboard shortcuts every day

⏱️

Saves Time

Short keys speed up tasks like copying and pasting. Instead of right-clicking and selecting from a menu, one key combo does the job instantly.

🚀

Increases Productivity

They make repetitive tasks easier. Professionals who know shortcuts can finish work much faster than those who rely only on the mouse.

💪

Reduces Effort

They minimize the need to switch between the keyboard and mouse. Keeping your hands on the keyboard keeps your workflow smooth and effortless.

Short Keys for MS Word

MS Word is a popular tool for creating documents. These short keys will make writing and editing easier.

📝

Microsoft Word Shortcuts

Action Short Key Quick Description
CopyCtrl+CCopies selected text or object to clipboard
PasteCtrl+VPastes content from clipboard
CutCtrl+XCuts selected text or object
UndoCtrl+ZReverses the last action taken
RedoCtrl+YRepeats or redoes the last undone action
Bold TextCtrl+BMakes selected text bold or removes bold
Italic TextCtrl+IMakes selected text italic or removes italic
Underline TextCtrl+UUnderlines selected text or removes underline
Save DocumentCtrl+SSaves the current document
Open New DocumentCtrl+NOpens a new blank document
Print DocumentCtrl+POpens the print dialog
Find TextCtrl+FOpens the Find toolbar to search text
Replace TextCtrl+HOpens Find & Replace dialog
Select AllCtrl+ASelects all content in the document
// MS Word Formatting Shortcuts — Memorize these!
Ctrl+B → Bold selected text
Ctrl+I → Italic selected text
Ctrl+U → Underline selected text
// Editing shortcuts
Ctrl+Z → Undo | Ctrl+Y → Redo
Ctrl+F → Find | Ctrl+H → Replace

Try this memory trick: Bold = Big and strong, Italic = Italian style (slanted), Underline = Under the text. For editing: Z goes back (Undo), Y goes forward (Redo). Think of Save = Secure your work!

Short Keys for MS Excel

MS Excel is used for managing data and performing calculations. These shortcuts will help you work more efficiently.

📊

Microsoft Excel Shortcuts

Action Short Key Quick Description
Insert New SheetShift+F11Inserts a new worksheet in the workbook
Auto SumAlt+=Automatically sums selected column or row
Open Save As DialogF12Opens the Save As dialog to rename/relocate file
Move to Next SheetCtrl+Page DownMoves to the next worksheet tab
Move to Previous SheetCtrl+Page UpMoves to the previous worksheet tab
Add or Edit CommentShift+F2Adds or opens a comment in a cell
Highlight Entire ColumnCtrl+SpaceSelects the entire column of active cell
Highlight Entire RowShift+SpaceSelects the entire row of active cell
Edit Selected CellF2Places cursor inside the cell for editing
Refresh DataAlt+F5Refreshes data connections in the workbook
Close WorkbookCtrl+WCloses the current workbook
// MS Excel Power Shortcuts
Alt + = → Auto-SUM a range of numbers
Shift + F11 → Insert new worksheet tab
Ctrl + Space → Select entire COLUMN
Shift + Space → Select entire ROW
F2 → Edit cell contents directly

Ctrl+Space selects an entire Column (vertical — like a column in a building going UP and DOWN). Shift+Space selects an entire Row (horizontal — like a row of seats going LEFT and RIGHT). Remember: Ctrl = Column, Shift = row (S is in Shift)!

Lab Activities

Practice in Real Applications

Apply what you've learned with these hands-on activities

📝

Lab Activity 1: MS Word

  • Open a new document using Ctrl+N
  • Type a paragraph on "Benefits of using keyboard shortcuts"
  • Use Ctrl+B to make a word bold
  • Use Ctrl+I to italicize a sentence
  • Use Ctrl+U to underline text
  • Use Ctrl+F to find a word
  • Save with Ctrl+S
📊

Lab Activity 2: MS Excel

  • Create a new spreadsheet
  • Enter numbers in cells A1 to A5
  • Use Alt+= to auto-sum the column
  • Click a cell and use Shift+F2 to add a comment
  • Use Shift+F11 to insert a new sheet
  • Navigate between sheets with Ctrl+Page Down
💻

Lab Activity 3: General Keys

  • Minimize all windows using Win+D
  • Lock the computer with Win+L and log back in
  • Open File Explorer using Win+E
  • Take a screenshot using Win+Shift+S
  • Switch between open programs using Alt+Tab
  • Refresh the desktop by pressing F5

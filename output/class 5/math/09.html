📖 Background

What is Information Handling?

Information handling is the process of collecting, organizing, displaying, and interpreting data to answer questions and make decisions. It is used every day — from cricket scorecards to weather reports!

🏏Did You Know?

Shahid Afridi's run rate of 7 runs per over is an example of an average — a single number that represents multiple values!

📊Did You Know?

Bar graphs were first used in the 1700s by William Playfair to show economic data. Today they are used in every field!

🔢Did You Know?

Tally marks have been used for thousands of years. Ancient peoples carved tally marks into bones and sticks to count things!

📐 Core Concept

Average (Arithmetic Mean)

The average is the overall representative value of a set of numbers. It tells us what a "typical" value looks like in the data.

📌 Formula
Average = Sum of all quantities ÷ Total number of quantities
Example: Average of 6, 10, 8, 4 → (6 + 10 + 8 + 4) ÷ 4 = 28 ÷ 4 = 7

🟢 When to Use Average

  • Finding run rate in cricket
  • Finding average speed of a vehicle
  • Finding average attendance in class
  • Finding average rainfall or temperature

📝 Key Points

  • Always add all quantities first
  • Then divide by the count of quantities
  • Average lies between the smallest and largest value
  • Average may not be a whole number

⚡ Quick Facts

  • First 5 even numbers: 2,4,6,8,10 → Average = 6
  • First 5 odd numbers: 1,3,5,7,9 → Average = 5
  • First 5 natural numbers: 1,2,3,4,5 → Average = 3

📊 Visual Data

Block, Column & Bar Graphs

Graphs help us see data visually, compare quantities quickly, and find patterns at a glance.

📊 Column / Block Graph

Vertical bars where each bar's height represents the quantity. Categories are on the horizontal axis, values on the vertical axis.

📈 Horizontal Bar Graph

Bars are drawn horizontally. Categories are on the vertical axis, values on the horizontal axis. Good for comparing labels.

📋 Data Organization

Data & Tally Charts

Data is information collected from any field. Tally marks help us organize and count data efficiently.

What is Data?

The information collected from any field of study is called data. It is mostly represented in numerical form.

Examples of data: Favourite colours of students, ages of class members, marks in examinations, cricket game records, weather records.

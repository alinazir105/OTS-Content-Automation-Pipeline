What is Hardware?

🖥️ Definition

A computer is made up of various components, some of which we can see and touch, while others are not visible. The parts we can touch are known as hardware.

ℹ️
Key Idea

If you can pick it up or touch it, it's hardware! Think of the keyboard, mouse, monitor — all hardware.

🗂️ Four Categories

⌨️
Input Devices
Keyboard, Mouse, Scanner, Mic, Camera, Joystick
⚙️
Processing Devices
Processor (CPU), Motherboard
🖨️
Output Devices
Monitor, Speakers, Printer
💾
Storage & Memory
Hard Disk, RAM, USB, DVD
🔧

Hardware Components

⌨️

Keyboard

The most commonly used device. It helps us enter letters, numbers, and instructions into the computer.

INPUT DEVICE
🖨️

Scanner

Lets us take a printed picture or document and turn it into a digital file on the computer.

INPUT DEVICE
🎙️

Microphone

Captures sound and sends it to the computer. It is also called a Mic.

INPUT DEVICE
🕹️

Joystick

Used mostly for playing games. It has a handle that can move in all directions to control the game.

INPUT DEVICE
📷

Digital Camera

Used to take pictures that can be saved and viewed on a computer.

INPUT DEVICE
🖥️

Monitor / LCD

Displays the output from the computer. It shows text, images, and videos on its screen.

OUTPUT DEVICE
🔊

Speakers

Produce sound from the computer. Used to listen to music, videos, and audio output.

OUTPUT DEVICE
🖨️

Printer

Produces a paper copy of documents and images from the computer.

OUTPUT DEVICE
⚙️

Processor (CPU)

The brain of the computer. It processes all instructions and data.

PROCESSING DEVICE
🔌
Connectors and Ports

Each part of the computer connects to the motherboard using special points called ports. The cables or ends of devices we use to connect to the ports are called connectors.

💾

RAM vs Hard Disk

🧠

RAM

Random Access Memory

RAM stores data temporarily. It is called "temporary memory" because it only keeps information when the computer is ON. When you turn the computer OFF, everything in RAM is lost!

⚡ Fast but Temporary

💽

Hard Disk

Permanent Storage

The hard disk is the computer's permanent storage. It stores all the files and information, even when the computer is turned OFF. Your games, photos, and documents are safe here!

📦 Large & Permanent

Feature 🧠 RAM 💽 Hard Disk
Storage Type Temporary Permanent
Data Lost When OFF? ✅ Yes — data is lost ❌ No — data is saved
Speed Very fast ⚡ Slower than RAM
Capacity Smaller (4GB–32GB) Much larger (500GB–4TB)
Purpose Running active programs Storing files, photos, games

🖥️ Motherboard

The motherboard is the main circuit board inside the computer. All the important parts of the computer, like the keyboard, mouse, and hard disk, are connected to the motherboard.

⚠️
Important!

If the motherboard stops working, the computer will not be able to function properly.

📦 Computer Casing

The computer casing is the box that holds important parts like the motherboard, hard disk, RAM, and processor.

🔩 Motherboard ⚙️ Processor 🧠 RAM 💽 Hard Disk 🔌 Power Supply

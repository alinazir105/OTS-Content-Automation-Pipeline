1. Colour Picker Tool

What is it?

The Colour Picker tool helps you pick a colour from one part of the figure and fill the same colour in any other part of the drawing.

Example: Pick a colour from a green leaf, then select the Fill with Colour tool and fill that same colour in the background (white area).

Steps to Use the Colour Picker Tool

  1. 1 On the Home tab, in the Tools group, click on Colour Picker.
  2. 2 Left-click on the required colour in the drawing to set it as the foreground colour.
  3. 3 Right-click on the colour to set it as the background colour.
  4. 4 Now select the Fill with Colour tool and fill the picked colour in another shape.

2. Magnifier Tool

What is it?

The Magnifier tool is used to zoom in and zoom out on a part of the drawing. It helps you see small details more clearly!

Left-click = Zoom In 🔍
Right-click = Zoom Out 🔎

Steps to Use the Magnifier Tool

  1. 1 On the Home tab, in the Tools group, click on the Magnifier tool.
  2. 2 Move the magnifier over the drawing.
  3. 3 Left-click to zoom in on the part of the drawing.
  4. 4 Right-click the magnifier to zoom out on a drawing.

3. Selection Tools

Selection tools let you choose specific parts of your drawing to move, copy, resize, or rotate.

⬜

1. Rectangular Selection

Selects a rectangle-shaped area in your drawing.

How: Home tab → Image group → Select → Rectangular selection → Click and drag
🌀

2. Free-Form Selection

Selects an irregular area of any shape.

How: Home tab → Image group → Select → Free-form selection → Click and drag around area
🔲

3. Select All

Selects the entire drawing at once.

How: Home tab → Image group → Select → Select All

Selection Operations

4. Moving the Selection Select an area → bring cursor inside the selection (it changes to four-sided arrows) → drag it to a new location.
5. Copy and Paste the Selection Select the area → click Copy (in Clipboard group) → click Paste → move the pasted area to the desired location.
6. Cut and Paste the Selection Select the area → click Cut (in Clipboard group) → click Paste → move the pasted area to the desired location.
7. Resizing the Selection Drag the selection's corners to resize it, or use the Resize option in the Image group for precise resizing.
🔄

4. Rotate or Flip Tool

What is it?

The Rotate or Flip tool lets you rotate or flip a drawing or a selected area. You can change the orientation of your image easily!

Rotate right 90° — turns the image 90 degrees clockwise
Rotate left 90° — turns the image 90 degrees anti-clockwise
Rotate 180° — flips the image upside down
Flip horizontal — mirrors left to right
Flip vertical — mirrors top to bottom

Steps to Rotate or Flip a Drawing

  1. 1 Select the drawing or the area you want to rotate.
  2. 2 Go to the Home tab → Image group → click Rotate.
  3. 3 Choose an option, like Rotate right 90°.

File Management in MS Paint

📄

Open a New File

  1. 1 Click on the Paint button.
  2. 2 Click on New option or press Ctrl + N.
A new blank white drawing area appears. Default name is "Untitled".
💾

Save a File

  1. 1 Click on the Paint button.
  2. 2 Click Save or press Ctrl + S.
  3. 3 Type the file name in the File name box.
  4. 4 Click the Save button.
📂

Open a Saved File

  1. 1 Click on the Paint button.
  2. 2 Click Open or press Ctrl + O.
  3. 3 Select the file name from the list.
  4. 4 Click the Open button.
🖼️

Setting Image as Wallpaper

In Paint, you can set your drawing as the wallpaper on the desktop!

  1. 1Find the saved picture in your folder.
  2. 2Right-click on the picture file.
  3. 3Select "Set as desktop background".
  4. 4Your drawing is now the wallpaper! 🎉

Lab Activity

🌹 Activity 1: Rose Garden

1 Draw a small red rose in MS Paint using drawing tools.
2 Use the Rectangular Selection tool to select the rose.
3 Press Ctrl + C to copy and Ctrl + V to paste.
4 Move the pasted roses to different locations on the canvas.
5 Use the Colour Fill tool to fill yellow and pink colours in some of the roses.

🌄 Activity 2: My Wallpaper

1 Draw a beautiful scenery — trees, mountains, sun, sky!
2 Use different colours and brushes to make it look amazing.
3 Save the drawing using Ctrl + S. Give it a nice name!
4 Find the saved file, right-click on it.
5 Select "Set as desktop background". Your art is now the wallpaper! 🎉

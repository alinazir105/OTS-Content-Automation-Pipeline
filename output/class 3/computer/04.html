What is Software?

🖥️ Software Defined

Software is a set of instructions given to a computer to perform a specific task. The games we play and the programs we run on a computer are examples of software.

⚙️ System Software

Designed to operate the hardware and provide an environment for running other software.

  • Operating Systems
  • Device Drivers
  • Utilities
  • MS Windows

📱 Application Software

Designed for the end user to perform specific tasks on the computer.

  • MS Word / Excel
  • MS Paint
  • PowerPoint
  • Internet Browsers

System Software

⚙️ What is System Software?

System software is designed to operate the hardware and provide an environment for running other software. It includes device drivers, utilities, and an operating system.

MS Windows is an example of an operating system. It is the most commonly used system software.

💡

An operating system is the master software that manages all other programs and hardware resources on your computer.

Device Drivers

🔌 What is a Device Driver?

When we buy a new computer part, it comes with its own software, which helps the operating system communicate with and use the new part. This software is called a device driver.

📠 For example: The device driver for a printer tells the computer how to communicate and operate the printer.

🖨️ Printer Driver

Tells the computer how to send documents to the printer and manage print jobs.

🖥️ Display Driver

Controls how images are shown on your computer screen with correct colours and resolution.

🔊 Sound Driver

Manages audio output so you can hear sounds and music from your computer speakers.

⚠️

Without a device driver, the hardware will not work properly. The operating system cannot communicate with the new device!

📱

Application Software

📱 What is Application Software?

Application software is designed for the user of the computer, also called the end user. These programs help users perform specific tasks such as creating documents, editing images, or browsing the internet.

🎨

MS Paint

Draw and create colourful pictures and digital art on your computer.

📝

MS Word

Write and format documents, letters, stories and reports easily.

📊

MS Excel

Work with numbers, create tables and make calculations quickly.

📽️

MS PowerPoint

Create beautiful slide presentations with text, images and effects.

🎵

Media Players

Play music, videos and movies on your computer screen.

🌐

Internet Browsers

Browse websites and explore the internet to find information.

💡

Hardware and software work together and cannot be used alone. You need both to make a computer work properly!

Lab Activity

💻 Computer Lab Practice

Go to your computer lab and practise opening and closing different application software like MS Paint and MS Word. Follow these steps:

  • Turn on the computer and wait for the operating system (Windows) to load.
  • Click on the Start button (🪟) at the bottom left of your screen.
  • Find and click on MS Paint to open it. Explore its tools!
  • Draw something using the paint tools — try different colours and shapes.
  • Close MS Paint by clicking the ✕ button at the top right.
  • Now open MS Word from the Start menu.
  • Type your name and your school name in the document.
  • Close MS Word and observe what happens (save prompt!).

Teacher's Note: Enhance the student's knowledge about software and its types through this hands-on lab activity. Encourage students to identify which software is system software and which is application software while exploring.

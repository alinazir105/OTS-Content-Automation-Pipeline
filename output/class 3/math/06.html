📖 Definition of Fractions

A fraction is a mathematical expression representing a part of a whole or a ratio between two numbers.

For example, if you cut a pizza into 4 equal slices and eat 1 slice, you have eaten 1/4 of the pizza!

Parts of a Fraction

🔄 How to Find Equivalent Fractions

1
Start with your original fraction (e.g., 2/4)
2
Choose a number to multiply both the numerator AND denominator by the same number
3
Example: 2/4 × 2/2 = 4/8 — both represent the same value!
4
You can also divide both numbers by the same amount to simplify: 4/8 ÷ 2/2 = 2/4

➕ Adding Fractions with Same Denominator

1
Check that the denominators are the same (e.g., both are 9)
2
Add only the numerators: 1/9 + 4/9 = (1+4)/9 = 5/9
3
The denominator stays the same! Never add the denominators.

➖ Subtracting Fractions with Same Denominator

1
Make sure the denominators match
2
Subtract the numerators: 7/9 − 1/9 = (7−1)/9 = 6/9
3
Keep the denominator unchanged!

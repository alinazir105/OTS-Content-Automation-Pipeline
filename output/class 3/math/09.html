Points & Line Segments

📍

What is a Point?

A point is the basic unit of Geometry. It marks a location but has no size, width, or length. We name a point with a capital letter.

Read as: point A, point B, point X
🗺️ Real Life: The location of any address on a map is a point!
📏

What is a Line Segment?

A line segment is the straight path between two points. It has a definite start and end — it does not go on forever.

Example: D————E
Read as: Line segment DE or ED
📐 Real Life: The edges of an eraser or a ruler are line segments!

Lines — Going On Forever!

What is a Line?

A line is a set of points that extends forever in opposite directions. Unlike a line segment, a line has no endpoints — it goes on and on in both directions! We show this with arrows on both ends.

Visual Comparison

LINE — extends forever both ways
←
G H
→
Read as: Line GH or line HG
LINE SEGMENT — has two endpoints
D E
Read as: Line segment DE or ED
💡 Remember: A line has arrows on BOTH ends (goes forever both ways). A line segment has dots on both ends (finite — has a start and end). A ray has a dot on ONE end and an arrow on the OTHER end.

Rays — Starting Point, No End!

What is a Ray?

A ray is the part of a line that has a starting point and goes on forever in one direction. It has one endpoint (the starting point) and one arrow (showing it goes on forever).

RAY — starts at K, goes forever toward J
K J
→
Read as: Ray KJ (always name the starting point FIRST!)

Quadrilaterals — Four-Sided Shapes!

What is a Quadrilateral?

A quadrilateral is a four-sided polygon with four angles. There are various types of quadrilaterals, each with unique properties based on their side lengths and angle measurements.

Rectangle

Four right angles. Opposite sides are parallel and equal in length.

Parallelogram

Opposite sides are parallel and equal in length. Angles are not necessarily right angles.

Trapezoid

Exactly one pair of parallel sides.

Square

All sides equal in length. Each angle is a right angle. A special type of rectangle!

Rhombus

All sides are equal in length — a type of equilateral quadrilateral. A parallelogram with all sides equal!

Circles — Perfectly Round!

What is a Circle?

A circle is a perfectly round shape where every point on the edge has the same distance from the centre.

Radius

The radius is the distance from the centre of the circle to any point on its edge.

Diameter

The diameter is a line that goes across the circle, passing through the centre. The diameter is twice the radius!

Formula: Diameter = 2 × Radius

What is Addition?

Addition means putting two or more numbers together to find the total. We use the plus (+) sign.

🔢

Place Values

Numbers have Hundreds (H), Tens (T), and Ones (O). We always add ones first!

📦

Carrying (Regrouping)

When ones add up to 10 or more, we carry the extra ten over to the tens column!

🌍

Real Life Use

We use addition every day — counting apples, toy cars, books in a library, and runners in a race!

💡

In this chapter, we will review adding 1-digit, 2-digit, and 3-digit numbers. We'll learn step-by-step with examples, practice problems, and fun activities!

💡 Understanding Addition

Building blocks: place value and carrying

Place Value — The Foundation

Every digit in a number has a place. Let's look at the number 368:

Hundreds (H)
3

3 × 100 = 300

Tens (T)
6

6 × 10 = 60

Ones (O)
8

8 × 1 = 8

So 368 = 300 + 60 + 8

How to Add Step by Step

1

Write the numbers vertically

Line up the Hundreds, Tens, and Ones columns carefully. Always align by place value!

2

Add the Ones column first

Start from the right! Add the ones digits. If the sum is 10 or more, write the ones digit and carry the tens digit.

3

Add the Tens column

Don't forget to add the carried digit if there is one! Again, carry to hundreds if the sum is 10 or more.

4

Add the Hundreds column

Add the hundreds digits including any carried digit. Write down the full result.

Add: 34 and 27

TO

Step 1 (Ones): 4 + 7 = 11 ones → write 1, carry 1 ten

Step 2 (Tens): 3 + 2 + 1(carried) = 6 tens

∴ 34 + 27 = 61

Example 3 — Adding 3-Digit Numbers

Add: 368 and 547

HTO
11
368
+ 547
915

Step 1 (Ones): 8 + 7 = 15 → write 5, carry 1

Step 2 (Tens): 6 + 4 + 1 = 11 → write 1, carry 1

Step 3 (Hundreds): 3 + 5 + 1 = 9 → write 9

∴ 368 + 547 = 915

Remember: Always start adding from the Ones column (rightmost), then move left to Tens, then Hundreds. This is so you can carry correctly!

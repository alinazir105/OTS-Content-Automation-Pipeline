Grammar Rules

Some and Any

These two words are used to talk about quantities. Knowing when to use each one is the key!

SOME

When to use SOME

  • In positive (affirmative) sentences
  • In polite requests or offers

🗣️ "I'd like some tea."
🗣️ "Would you like some help?"
🗣️ "Can I have some water?"

ANY

When to use ANY

  • In negative sentences
  • In questions
  • In positive sentences meaning "it doesn't matter which"

🗣️ "I don't have any homework."
🗣️ "Have you got any money?"
🗣️ "You can take any bus."

No for Emphasis

NO

Use no instead of not … any for stronger emphasis.

"There isn't any bread." → "There's no bread!"

Summary Table

ContextSOME (Affirmative/Requests)ANY (Negative/Questions)
Positive Sentences ✔ I have some apples. ✗ Not used (unless "doesn't matter which")
Negative Sentences ✗ ✔ I don't have any money.
Questions ✔ Can I have some water? (Request) ✔ Do you have any books?
Emphasis in Negatives ✗ ✔ There is no sugar left.
Offers ✔ Would you like some help? ✗
Choice Doesn't Matter ✗ ✔ Take any seat.

Complete the dialogue using some, any, a, or no

Mum: We've ___ friends coming for dinner tonight.

Sami: Would you like ___ help?

Mum: I'm making spaghetti but there's ___ pasta in the cupboard.

Sami: OK. I'll buy ___ spaghetti. Do we need ___ other food?

Mum: I've ___ meat and tomatoes, but there are ___ drinks.

Sami: I'll get ___ juice. What type would you like?

Mum: Get ___ type. I don't mind.

Sami: There's ___ time to waste. I'll go now.

Step 1 — "We've ___ friends..."

✅ Answer: some — Positive sentence, we know friends are coming.

Step 2 — "Would you like ___ help?"

✅ Answer: some — This is a polite offer, so we use some.

Step 3 — "There's ___ pasta..."

✅ Answer: no — Emphasising that pasta is completely absent (stronger than "not any").

Step 4 — "I'll buy ___ spaghetti..."

✅ Answer: some — Positive sentence: Sami will buy spaghetti.

Step 5 — "Do we need ___ other food?"

✅ Answer: any — This is a question, so we use any.

Step 6 — "I've ___ meat and tomatoes..."

✅ Answer: some — Positive sentence, Mum has meat and tomatoes.

Step 7 — "...but there are ___ drinks."

✅ Answer: no — Emphasising there are zero drinks.

Step 8 — "I'll get ___ juice."

✅ Answer: some — Positive sentence.

Step 9 — "Get ___ type. I don't mind."

✅ Answer: any — "It doesn't matter which" — this is the special case of any!

Step 10 — "There's ___ time to waste."

✅ Answer: no — Emphasis: absolutely no time left.

Grammar Concept

Indefinite Pronouns

Indefinite pronouns refer to an unknown person, thing, or place. They follow the same some/any pattern!

📌 Definition

An indefinite pronoun does not refer to any specific person, thing, or place. Examples: Someone is at the door. | I can't find my book anywhere.

SOME-

Affirmative Sentences

  • someone — a person
  • somewhere — a place
  • something — a thing

🗣️ "Someone has eaten my sandwich."

🗣️ "Sana is going somewhere."

🗣️ "There is something wrong here."

ANY-

Negative & Questions

  • anyone — a person
  • anywhere — a place
  • anything — a thing

🗣️ "Is anyone here?"

🗣️ "I cannot see anything."

🗣️ "She has not gone anywhere."

NO-

Emphatic Negatives

  • no one — not any person
  • nowhere — not any place
  • nothing — not any thing

🗣️ "No one has seen Ali."

🗣️ "There is nothing to eat."

EVERY-

All-Inclusive

  • everyone — all people
  • everywhere — all places
  • everything — all things

🗣️ "There is beauty everywhere on Earth."

🗣️ "Everyone likes this game."

📌 Quick Reference: Some vs Any

  • SOMEPositive sentences: "I have some apples."
  • SOMEPolite offers: "Would you like some tea?"
  • SOMERequests: "Can I have some water?"
  • ANYNegatives: "I don't have any money."
  • ANYQuestions: "Have you got any?"
  • ANY"Doesn't matter": "Take any bus."
  • NOEmphasis: "There's no bread!" (stronger)

💡 Memory Tips

  • TIPSOME = positive & sharing (offers, requests)
  • TIPANY = questions & negatives (also "whichever")
  • TIPNO = extra strong negative (no verb needed)
  • TIPEVERY- = includes absolutely everyone / everything

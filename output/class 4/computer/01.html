Foundation

Hardware vs Software

Computers are made up of both software and hardware. Software refers to the programs and applications that operate on a computer, while hardware includes the physical components that run these programs.

Unlike software, hardware can be seen and touched. The key parts of computer hardware include the CPU, memory, motherboard, graphics card, sound card, and the computer casing.

🖥️ What is the System Unit?

The System Unit is the part of a computer that contains the primary devices. It performs operations and produces results for complex calculations. It includes the motherboard, CPU, RAM, and other components, as well as the case in which these devices are enclosed.

💾

Software

Programs and applications — cannot be seen or touched. Examples: Windows, Chrome, games.

🔧

Hardware

Physical components you can see and touch. Examples: CPU, keyboard, monitor, RAM.

Component 1

The Motherboard

The motherboard is the main circuit board that connects all parts of a computer. It contains key components like the CPU, RAM, ROM, ports, and expansion slots.

Similar to a nervous system, the motherboard enables communication between all parts of the computer. Made of layered fiberglass, it contains copper circuits that carry electrical signals to different components.

🔌 Input/Output Ports

Devices such as input and output peripherals can be attached, removed, or upgraded through its ports as needed by the user.

Component 2

The Microprocessor (CPU)

🧠 What is the CPU?

The CPU (Central Processing Unit) or microprocessor is the brain of the computer, made up of a silicon chip containing millions of transistors that process data. It performs all the calculations needed to operate the computer with high speed and accuracy.

The microprocessor receives instructions from software programs and carries them out using its internal components. Every action you take on a computer — clicking, typing, loading a website — involves the CPU processing data at incredible speeds.

⚙️ How the CPU Processes Data — Step by Step

Step 1 → You type a key on the keyboard (Input)
Step 2 → The signal travels to the Motherboard via circuits
Step 3 → The Control Unit receives and decodes the instruction
Step 4 → The ALU performs any needed calculations or comparisons
Step 5 → Result is stored temporarily in Registers or Cache
Step 6 → Output is sent to the display (Output)

Deep Dive

5 Key Parts of the CPU

The CPU (microprocessor) has five key components that work together to process all computer operations:

1
➕

Arithmetic Logic Unit (ALU)

Handles arithmetic operations (addition, subtraction, multiplication, division) and logical comparisons (comparing, selecting, matching data). It is the calculating engine of the CPU.

2
🎮

Control Unit (CU)

Manages the flow of data and instructions between other computer units, coordinating operations like a traffic controller. It tells other parts what to do and when.

3
⏱️

Clock

Generates electrical pulses that dictate the timing of instruction execution. CPU speed is measured in MHz or GHz. A faster clock means more instructions per second.

4
📦

Registers

Temporary storage for data being processed. Available in sizes of 8, 16, 32, or 64 bits. Registers are the fastest type of storage inside the CPU — right next to the ALU.

5
⚡

Cache

A fast, intermediate storage inside the microprocessor for temporarily holding processed information. Available as internal (inside the CPU) or external (outside the CPU) cache.

🔁 Memory Speed Hierarchy (Fastest → Slowest)

Registers → Cache → RAM → Storage (HDD/SSD) — The closer the storage is to the CPU, the faster it operates!

💡 Show Answer

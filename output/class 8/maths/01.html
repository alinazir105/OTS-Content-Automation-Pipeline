Chapter 1

What is a Set?

In mathematics, a collection of things is called a set. Sets form the foundation of modern mathematics.

"A set is a collection of well-defined and distinct objects."
✅
Well Defined
A set must have some specific property that clearly determines which objects belong to it — no ambiguity allowed.
🔢
Distinct
All objects in a set must be different from each other. Repetition is not allowed in set notation.
🧩
Object / Element / Member
Each individual item in a set is called an element or member. It can be a number, letter, person, or any object.
// Example sets A = {1, 2, 3, 4, 5} ← Tabular (Roster) Form
B = {x | x is a natural number} ← Set-Builder Form
C = Set of vowels in English ← Descriptive Form Symbols: ∈ (belongs to) · ∉ (does not belong to) · | (such that)
Chapter 2

Types of Sets

Sets are classified based on their size and the nature of their elements.

1. Empty Set { }

A set with no elements at all. Also called the null set or void set.

{ } or ∅

2. Singleton Set {a}

A set containing exactly one element.

{2} or {a}

3. Finite Set {a, b, c}

A set with a countable, limited number of elements.

{1, 2, 3, 4, 5}

4. Infinite Set

A set with an unlimited number of elements that continue forever.

{x | x is a natural number}
Chapter 3

Set-Builder Notation

Set-builder notation defines a set by describing the properties its elements must satisfy, rather than listing them explicitly.

// General form { x | property of x } Read as: "the set of all x such that x satisfies the property"
📝
Example 1 — Descriptive
B = {x | x is an even number greater than 2}
B = {4, 6, 8, 10, ...}
🔣
Example 2 — Using Symbols
C = {x | x ∈ N ∧ x < 9}
C = {1, 2, 3, 4, 5, 6, 7, 8}
🔑
Key Symbols
∈ — belongs to
∉ — does not belong to
∧ — AND (conjunction)
∨ — OR (disjunction)
| — such that

Chapter 4

Subsets & Power Sets

Set X is a subset of set Y if every element of X is also an element of Y.

Visualizing Subsets

B = {1,2}
A = {1,2,3,4,5}

Since every element of B is also in A, we write: B ⊆ A

∅ ⊆ every set
Every set ⊆ itself
⊂
Proper Subset (⊂)
B is a proper subset of A if B ⊆ A and B ≠ A. Every element of B is in A, but A has at least one more element.
A = {1,2,3}, B = {1,2} → B⊂A
⊆
Improper Subset (⊆)
A is an improper subset of B if A = B. Every set is an improper subset of itself.
A = {1,2,3}, B = {3,2,1} → A⊆B
2ⁿ
Number of Subsets
If a set has n elements, it has 2ⁿ total subsets, including the empty set and the set itself.
n=0→1, n=1→2, n=2→4, n=3→8

Power Set P(A)

The power set is the set of ALL possible subsets. If A = {a, b}, then P(A) has 2² = 4 elements.

// A = {a, b} → P(A) P(A) = { ∅, {a}, {b}, {a,b} } Number of subsets = 2² = 4

Example: A = {x, y, z} — all subsets (2³ = 8)

Chapter 5

Set Operations

Five fundamental operations allow us to combine and manipulate sets.

∪ Union

The set of all elements that are in either or both sets.

A={1,2} ∪ B={2,3} = {1,2,3}
∩ Intersection

The set of elements common to both sets.

A={1,2} ∩ B={2,3} = {2}
− Difference

Elements in one set that are not in the other.

A={1,2,3} − B={2,3} = {1}
′ Complement

Elements not in the set, within the universal set U.

U={1,2,3,4}, A={1,2} → A'={3,4}
Δ Symmetric Difference

Elements in either A or B but not both.

A Δ B = (A−B) ∪ (B−A)

Key Properties of Δ

Commutative: A Δ B = B Δ A
Associative: (A Δ B) Δ C = A Δ (B Δ C)
Identity: A Δ ∅ = A
Self-inverse: A Δ A = ∅
Chapter 6

Laws of Set Operations

Three fundamental laws govern how set operations interact with each other.

Commutative Laws

The order of sets does not matter for union or intersection.

A ∪ B = B ∪ A
A ∩ B = B ∩ A

Verification: A={1,2,3}, B={1,3,5}

LHS:A ∪ B = {1,2,3} ∪ {1,3,5} = {1,2,3,5}
RHS:B ∪ A = {1,3,5} ∪ {1,2,3} = {1,2,3,5} ✓
LHS:A ∩ B = {1,2,3} ∩ {1,3,5} = {1,3}
RHS:B ∩ A = {1,3,5} ∩ {1,2,3} = {1,3} ✓
Associative Laws

The grouping of sets does not affect the result.

A ∪ (B ∪ C) = (A ∪ B) ∪ C
A ∩ (B ∩ C) = (A ∩ B) ∩ C

Verification: A={1,2,3}, B={2,3,4}, C={3,4,5}

B∩C:{2,3,4} ∩ {3,4,5} = {3,4}
LHS:A ∩ {3,4} = {3}
A∩B:{1,2,3} ∩ {2,3,4} = {2,3}
RHS:{2,3} ∩ {3,4,5} = {3} ✓
Distributive Laws

Union distributes over intersection, and vice versa.

A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

Verification: A={1,2,3}, B={2,4,6}, C={2,3,6}

B∩C:{2,4,6} ∩ {2,3,6} = {2,6}
LHS:A ∪ {2,6} = {1,2,3,6}
A∪B:{1,2,3,4,6}
A∪C:{1,2,3,6}
RHS:{1,2,3,4,6} ∩ {1,2,3,6} = {1,2,3,6} ✓

Chapter 7

De Morgan's Laws

Two powerful laws relating complements with union and intersection.

First Law

(A ∪ B)' = A' ∩ B'

The complement of a union equals the intersection of the complements.

Second Law

(A ∩ B)' = A' ∪ B'

The complement of an intersection equals the union of the complements.

Worked Example

U={1,2,3,4,5,6}, A={1,3,5}, B={2,4,6} — Verify (A∩B)'=A'∪B'

LHS: (A∩B)'

A∩B = {1,3,5}∩{2,4,6} = {}
(A∩B)' = U−{} = {1,2,3,4,5,6}
LHS = {1,2,3,4,5,6}

RHS: A'∪B'

A' = U−A = {2,4,6}
B' = U−B = {1,3,5}
A'∪B' = {2,4,6}∪{1,3,5}
RHS = {1,2,3,4,5,6} ✓
Chapter 8

Venn Diagrams

Venn diagrams are graphical representations of sets using overlapping circles inside a rectangle (universal set).

Union: A ∪ B ∪ C

Shaded region = A ∪ B ∪ C (all elements in any set)

Intersection: A ∩ B ∩ C

Shaded region = A ∩ B ∩ C (elements in all three sets)

Complement: A'

A' = everything in U that is NOT in A

Distributive Law: A∪(B∩C)

Darker green = A ∪ (B∩C) = (A∪B) ∩ (A∪C)

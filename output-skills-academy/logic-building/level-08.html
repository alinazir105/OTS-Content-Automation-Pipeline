Core Concept

Loops: Repetition With Control

A loop is an instruction that says: "Keep doing this… until I tell you to stop." Without loops, we'd have to write the same thing hundreds of times.

🔁
FOR Loop
Use when you know exactly how many times to repeat. Like handing a sticker to each of 30 students.
FOR each student FROM 1 TO 30:
  give sticker
→ Runs exactly 30 times
⬆️
WHILE Loop
Use when you repeat as long as a condition is true. Like eating until you're full.
WHILE still_hungry:
  eat one bite
→ Stops when not hungry
🛑
Exit Condition
The rule that stops the loop. Without it, the loop never ends. Always ask: "What makes this stop?"
counter = 1
WHILE counter <= 10:
  counter = counter + 1
→ Exit when counter = 11
♾️
Infinite Loop
When the exit condition is never reached, the loop runs forever. This freezes programs — a bug to avoid!
counter = 1
WHILE counter <= 10:
  ← counter never changes!
→ Loops forever ♾️

Think Deeper

Infinite Loop Trap

Some of the loops below will run forever. Some will stop. Can you tell which is which? Click each loop to classify it. Score 5/6 to pass!

Loop A
x = 5
WHILE x > 0:
  print x
← nothing changes!
This loop checks if x > 0. x starts at 5. But x never changes inside the loop.
Loop B
count = 1
WHILE count <= 10:
  print count
  count = count + 1
Count starts at 1 and increases by 1 each time. It will eventually reach 11.
Loop C
score = 0
WHILE score < 100:
  score = score - 1
  print score
Score starts at 0 and keeps decreasing. It will never reach 100 by going down!
Loop D
FOR each player
FROM 1 TO 11:
  assign jersey number
END LOOP
This loop has a fixed range: 1 to 11. It will run exactly 11 times for a cricket team.
Loop E
fuel = 100
WHILE fuel > 0:
  drive 1 km
  fuel = fuel - 5
Fuel starts at 100 and decreases by 5 each loop. It will reach 0 after 20 loops.
Loop F
WHILE true:
  check for new message
  display notification
← no exit condition!
This loop has the condition "true" — which is ALWAYS true. It never stops on its own.

Real-World Connection

Loops Are Everywhere

Every time something repeats automatically in the digital world, there's a loop running behind it.

▶️
YouTube Autoplay
YouTube uses a loop: WHILE you keep watching → suggest next video. It only stops when you close the app. That's an intentional near-infinite loop!
📶
WhatsApp Ping
Your phone constantly runs a loop: Check server for new messages → if found, notify → repeat every few seconds. That's a WHILE loop running all day.
🏏
Cricket Scorecard
FOR each over FROM 1 TO 20: record runs. That's a FOR loop — exactly 20 overs, exactly 20 repetitions. T20 cricket in loop logic!
🚦
Karachi Traffic Lights
Traffic lights run a loop: Red → Green → Yellow → Red → … This loop only breaks when a traffic officer overrides it manually.

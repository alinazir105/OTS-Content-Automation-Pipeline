CORE CONCEPT

Conditional Logic

IF / THEN

An IF statement tests a condition. If the condition is TRUE, the THEN action runs.

IF temperature > 35°C THEN turn on the fan

Think of IF as asking a question. THEN is what you do when the answer is YES.

IF / THEN / ELSE

The ELSE handles the NO path — what happens when the condition is FALSE.

IF score >= 50 THEN display "PASS" ELSE display "TRY AGAIN"

ELSE ensures EVERY outcome is covered. No loose ends.

Nested Conditions — Conditions Inside Conditions

Sometimes one decision leads to another. You can put an IF inside another IF. This is called nesting.

IF it_is_weekend = TRUE IF weather = "sunny" THEN go to the park ELSE watch TV inside ELSE do your homework // Three different outcomes from two conditions

REAL-WORLD CONNECTION

IF/THEN Logic in the Real World

Conditional logic isn't just theory. It powers everything you interact with every day.

🎮

Video Games

Every action in a game runs through conditional logic. Health, enemies, scores — all decisions.

IF player.health = 0 THEN game_over = TRUE ELSE continue_playing
🚦

Karachi Traffic Signals

Smart traffic lights use conditional logic to manage flow at busy intersections like Tariq Road.

IF cars_waiting > 10 THEN extend_green_time ELSE normal_cycle
📱

App Notifications

Your phone decides whether to buzz, stay silent, or show a banner based on layered IF rules.

IF do_not_disturb = ON IF caller = "Ammi" THEN ring_loud ELSE stay_silent
🏏

Cricket Team Selection

Selectors use conditional criteria: batting average, fitness, form — all IF/THEN decisions.

IF batting_avg >= 40 AND fitness = "PASS" THEN select_player ELSE consider_alternatives

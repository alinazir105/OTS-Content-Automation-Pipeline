Core Concept

What Is Decomposition?

The Big Idea

Decomposition means breaking a complex problem into smaller, simpler parts. Each part is easier to understand, easier to solve, and easier to explain to someone else. When all parts are solved, the big problem is solved too.

Why It Works

Our brains can only hold about 7 things in working memory at once. Decomposition works with your brain — not against it. By shrinking problems, you make thinking possible instead of overwhelming.

The Three Levels

Level 1 — System: The big thing (e.g. "School Canteen").
Level 2 — Sub-systems: Main parts (Queue, Food, Payment).
Level 3 — Tasks: Specific actions inside each part.

Decomposition vs Giving Up

When a problem feels too big, most people give up. Thinkers who know decomposition never give up — they just break the problem smaller until each piece feels manageable. Then they start solving.

Think Deeper

Reverse Decomposition

Decomposition usually goes top-down — big system → small tasks. But great thinkers can also go bottom-up: given a list of tasks, identify the bigger system they all belong to.

Here are 8 tasks. They all belong to the same system. Which one?

Check if seat available Detect motion at door Send alert to phone Lock / unlock doors Record camera footage Set alarm schedule Trigger alarm sound Notify emergency contact

Which system do all these tasks belong to?

✅ Correct — Home Alarm System!

Each task ("detect motion", "lock doors", "send alert") is a sub-task of one system. Notice how some tasks look like they could belong to a library (check availability) but the majority anchor the pattern to home security. This is reverse decomposition — reading the pattern from parts to whole.
Real-World Connection

Decomposition in the Wild

Every large achievement in human history used decomposition. Here's how this exact thinking skill shows up in the real world.

🚀

NASA Moon Landing

Getting to the moon is impossibly complex as one problem. NASA broke it into trajectory, life support, navigation, communication, re-entry — each solved by a different team. Decomposition made the impossible possible.

📱

Building a Mobile App

WhatsApp is one app — but its engineers work on messaging, media, security, notifications, and UI as completely separate sub-systems. That's decomposition at scale, used every day in tech.

🏙

Karachi Traffic Problem

Karachi traffic can't be "fixed" as one thing. Decompose it: signal timing, road width, driver behaviour, public transport gaps, parking rules. Each sub-problem now has a real solution.

🏥

Diagnosing a Patient

A doctor doesn't treat "being unwell". They decompose: symptoms → systems affected → possible causes → tests → diagnosis. Medicine runs on decomposition every single day.

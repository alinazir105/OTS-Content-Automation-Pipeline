Core Concept

What is an Algorithm?

An algorithm is simply a set of clear, ordered steps to solve a problem or complete a task. You already use algorithms every day — you just didn't know they had a name.

📋
A Recipe is an Algorithm
Every recipe tells you exactly what to do, in what order. Skip a step or do them out of order and the dish goes wrong. That's an algorithm in the kitchen.
// Recipe Algorithm STEP 1: Heat oil in pan STEP 2: Add onions STEP 3: Stir for 3 minutes STEP 4: Add tomatoes DONE
🗺️
Directions are an Algorithm
"Turn left at the signal, then go straight for 200 metres, then turn right at the school." These are ordered steps — an algorithm for finding a location.
// Navigation Algorithm STEP 1: Start at home STEP 2: Turn left at signal STEP 3: Go straight 200m STEP 4: Turn right at school ARRIVE
👟
Tying Shoes is an Algorithm
You learned to tie your shoes in exact steps. If you cross the laces before making the loop, it doesn't work. Order matters — always.
📐
The 3 Rules of a Good Algorithm
①

Clear — Every step is unambiguous. No guessing.

②

Ordered — Steps happen in a specific sequence.

③

Finite — It has a definite start and a definite end.

Real-World Connection

Algorithms in the Real World

Every time you use technology, an algorithm is running. Here are places you encounter them every single day.

🗺️
Google Maps
When you ask Maps for directions, it runs a pathfinding algorithm. It checks thousands of possible routes, calculates distance and time, then gives you the best sequence of turns to take. Every direction is one step in an algorithm.
🏏
Cricket Scorecard
The scoring system in cricket follows an algorithm: ball bowled → check if wicket → add runs → update over count → check if innings over. Each ball is a new step in a very precise sequence.
🚦
Karachi Traffic Lights
Traffic lights follow a timing algorithm: Red for 60s → Green for 45s → Amber for 5s → Red again. A simple sequence — but get the order wrong and you cause an accident.
🧑‍🍳
School Canteen
The canteen runs on a serving algorithm: take tray → choose food → get charged → sit down → eat → return tray. If a student tries to eat before paying, the system breaks. Sequence = order = fairness.
